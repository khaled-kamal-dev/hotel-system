# 🏨 Nile House - Hotel Management System
### Full-Stack Hotel System with Node.js, Express, MySQL & AI Chatbot

نظام متكامل لإدارة الفنادق مبني طبقاً لمخططات **ERD**, **Class Diagram**, **Use Case Diagram**, و **Sequence Diagrams (1 to 5)** مع واجهة عصرية تدعم اللغتين العربية والإنجليزية.

---

## 🌟 المميزات والمكونات الجديدة المضافة (New Features)

1. **دعم كامل للغتين (العربية / English)**:
   - زر سريع في الهيدر (`🌐 العربية / English`) للتبديل الفوري بين اللغتين.
   - دعم اتجاه الكتابة من اليمين لليسار (`dir="rtl"`) للغة العربية و(`dir="ltr"`) للإنجليزية مع خط عربي متناسق.

2. **صور وفوتوغرافيا افتراضية فاخرة لكل غرفة**:
   - صور عالية الجودة تمثل كل نوع من الغرف (الغرف الفردية Single، المزدوجة Double، والأجنحة الفاخرة Suite) مع شارات رقم الغرفة وحالتها.

3. **إخفاء الحسابات المسجلة من الواجهة لحماية الخصوصية**:
   - تم إخفاء صندوق بيانات الحسابات من صفحة تسجيل الدخول حتى لا يراها أي زائر، مع الاحتفاظ ببيانات التجربة للمشرفين في هذا الملف أدناه.

4. **تخصيص الحجز مع الوجبات والخدمات والرفاهيات الإضافية (Add-ons)**:
   - عند الضغط على "حجز الغرفة"، تفتح نافذة مخصصة تمكّن النزيل من اختيار:
     - **نظام الوجبات (Meal Plans)**:
       - إقامة فقط (0 ج.م).
       - شامل الإفطار يومياً (+100 ج.م / ليلة).
       - شامل إفطار وغداء نصف إقامة (+250 ج.م / ليلة).
     - **خدمات ورفاهيات إضافية (Add-ons)**:
       - 🛁 جاكوزي خاص مجهز داخل الغرفة (+300 ج.م).
       - 🎮 جهاز بلايستيشن / سوني في الغرفة (+200 ج.م).
       - 🏛️ مرشد سياحي خاص لمعالم القاهرة (+500 ج.م).
   - يتم احتساب التكلفة الإجمالية لحظياً وإضافتها لطلب خدمة الغرف وفاتورة الحجز تلقائياً دون الإخلال بهيكل الداتابيز.

5. **شات بوت ذكي متصل بقاعدة البيانات (Sequence 2)**:
   - يجيب النزيل فورياً من واقع جدول الغرف والأسعار وحجوزات النزيل، مع إمكانية التحويل التلقائي أو بضغطة زر لموظف الاستقبال ليرد مباشرة.

## 🛠️ خطوات التشغيل (Setup & Run)

1. **استيراد قاعدة البيانات**: استورد ملف `database/hotel_system.sql` في MySQL (عبر phpMyAdmin أو Workbench).
2. **التثبيت والتشغيل**:
   ```bash
   cd "hotel-system"
   npm install
   npm start
   ```
3. **فتح الموقع**: توجه إلى المتصفح على:
   ```
   http://localhost:3000
   ```
